# 親のセッション(将軍)の規約

将軍とは、リポジトリで作業を指揮する親のセッションのことである。このファイルは、将軍が作業を指揮する前に読むものと、引き継ぎの運用を定める。

## 将軍が読むもの

将軍は、作業を指揮する前に次を読む。短い質問に答えるだけのセッションは読まなくてよい。

- `README.md`
- `~/.claude/規約/` の `作業の進め方.md`・`オーナーとの対話.md`・`思考を伝えるための文章・表示設計方針.md`・`文章と語.md`・`レビュー.md`
- `~/.claude/shared-knowledge/deprecated_words.csv`(名前か文章を書く前に読む)

将軍が自分でコードを書くか検収するときは、`.claude/commands/rule.md` の「コードを書く・検査する(C#)」の行のファイルも読む。C# の規約は ONE.O.NET にある。

## 部品を足すときの決まり

WinUI 3 の部品の薄い包みとして一般に必要な関数と型は、ONE.O.NET のコードを見ずに、先にそろえる(ONE.O.NET の issue #12 の1)。ONE.O.NET に要るものから逆算しない。それより後に足りないと分かった関数や型は、先に想像で作らず、使われた形から足す(ONE.O.NET の `csharp_coding_rules.md` 第9条の5)。

## 引き継ぎ

将軍は、セッションを閉じるとき・再起動するとき・作業を区切って止めるときに、cost-meter のスキル `handoff` で引き継ぎを書く。将軍は、会話の逐語の開発スレッドをリポジトリに作らない。コミットは `~/.claude/規約/作業の進め方.md` の節「コミットの粒度」に従う。
